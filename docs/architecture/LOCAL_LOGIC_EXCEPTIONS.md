\# Local Logic Exceptions



Ce fichier liste les exceptions temporaires acceptées.



Une exception doit toujours préciser :



\- Fichier

\- Logique locale

\- Raison temporaire

\- Moteur générique cible

\- Passe prévue pour suppression

\- Risque métier



\## Exceptions connues à classifier



À remplir après le premier audit global.
